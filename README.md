# Walmart Sales Analysis

## Project Overview

This project analyzes Walmart weekly sales data using
MySQL and Tableau.

The objective is to identify sales trends, store performance,
holiday impact, and sales volatility.

## Tools Used

- MySQL Workbench
- Tableau Public
- GitHub

## Dataset

The dataset contains weekly Walmart sales information including:

- Store
- Date
- Weekly Sales
- Holiday Flag
- Temperature
- Fuel Price
- CPI
- Unemployment

## SQL Analysis

I performed 19 SQL analyses covering:

- Overall sales
- Store performance
- Average sales
- Top and bottom performing stores
- Yearly sales
- Monthly sales
- Holiday vs non-holiday sales
- Store rankings
- Store contribution to total sales
- Sales volatility
- Statistical analysis
